# Archived Docker/Azure Deployment Files

These files were the original deployment configuration for Azure Container Apps.

The application has been migrated to Vercel serverless deployment.

## Files:
- `Dockerfile` - Production Docker image configuration
- `deploy.sh` - Azure CLI deployment script
- `container-apps.yaml` - Azure Container Apps Kubernetes manifests

## To restore Docker deployment:
Move these files back to the `deployment/` directory.
